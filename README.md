# OmniDecompiler-bspsrc-
A map converter and decompiler designed to completely replace legacy tools like bspsrc. Built specifically for modders, level designers, and archival hobbyists, this tool eliminates old engine constraints and file-size limitations. 

Key Features:
• No Map Limits: Eliminates crashes on massive, high-poly Source engine maps.
• Retro Engine Support: Native, comprehensive compatibility with GoldSrc (HL1) and Quake .Map or .bsp formats.
• Automated Texture Archiving: Automatically extracts and bundles .wad files alongside your converted .vmf maps. (work in progress)
